# Bloom 🌸

E-commerce full-stack de uma loja de roupas online, com foco em uma experiência de compra elegante e identidade visual em tons de rosa. Projeto pessoal desenvolvido para praticar desenvolvimento web de ponta a ponta (frontend + backend).

## ✨ Funcionalidades

- Catálogo de produtos com imagens
- Cadastro e login de usuários com autenticação JWT
- Perfil de usuário
- Gerenciamento de endereços
- Seed de dados para popular o catálogo automaticamente

## 🛠️ Tecnologias

**Frontend**
- React + Vite
- Tailwind CSS

**Backend**
- Node.js + Express
- MongoDB com Mongoose
- Autenticação com JWT e bcrypt
- Upload de imagens com Multer

## 📁 Estrutura do projeto

    bloom/
    ├── frontend/   # React + Vite + Tailwind
    └── backend/    # API Express + MongoDB

## 🚀 Como rodar localmente

Pré-requisito: Node.js instalado.

### Backend

    cd backend
    npm install
    npm run seed    # popula o banco com dados de exemplo
    npm run dev

### Frontend

    cd frontend
    npm install
    npm run dev
